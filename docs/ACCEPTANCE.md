## 浏览器实测

Chromium，桌面 1440×960、手机 390×844、窄屏 320×720。

- 搜索“嘉年华”，选择目的地，出现实际 7.9 km / 7.1 km 路线方案。
- 开始导航后出现绿色路线，指引距离随车辆位置更新。
- “偏离原路线”后自动完成新路线请求，保留目的地并继续行驶。
- “驶出道路”后显示距最近道路约 510 m 的琥珀色虚线与返回指引；点击模拟返回后逐步靠近，回到道路后重新算路并恢复驾驶。
- 东京塔短途导航到达、重新导航、暂停操作通过。
- 收藏目的地后按钮变为“取消收藏目的地”，刷新后数据仍保留。
- 最新布局中不存在品牌页头，导航定位为蓝色箭头，右侧工具栏位于黑色导航栏下方。
- 手机 document.scrollWidth 与 viewport 同为 390，无页面横向溢出。

- 320 像素窄屏下，长地名“立山黑部阿尔卑斯山脉路线”未溢出，页面宽度与视口一致。
- 注入算路接口 503 后显示失败反馈，恢复服务并点击重新计算后成功获得路线。
- 生产版本浏览器无非预期运行错误（仅有测试主动注入的 503）。

## 实机边界

仍使用 mock 遥测。真实 UDP 接入、高架/隧道精确地图匹配、道路级禁转规则、避开障碍物的越野返回路径均未作实机验收。当前返回道路虚线是方向提示，不是无障碍路径保证。详见 README 与 TELEMETRY 文档。
